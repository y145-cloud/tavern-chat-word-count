# 角色卡字数统计（Chat Word Count）

适配 **SillyTavern** 与 **TauriTavern** 的只读统计扩展：把一张角色卡下的所有聊天分别统计，再汇总展示。支持按标签筛选正文（例如只看 `<content>…</content>`），千楼以上的聊天也不会一次性渲染卡死。

> 这是独立扩展，不修改、不依赖“楼层正文计数器”脚本。默认排除规则与它一致，所以单层数字通常能和楼层徽标对上；如果你在楼层计数器里改过标签或模式，请在本扩展里填同样的规则。

## 功能

- **按角色卡汇总**：总字数、总字符数、聊天数、总楼层。
- **分聊天查看**：当前聊天、每个聊天各自的楼层/字数/字符数/最后消息时间。
- **按标签筛选**：
  - `排除标签`：默认排除 `think`、`details`、`status`、`updatevariable` 等思考/状态块；
  - `只取标签`：只统计指定标签内的文字，例如 `content`；
  - 支持 `<content>` 写法、空格/逗号/顿号/分号分隔、同名标签嵌套。
- **两种计数单位**：
  - `字数`：中日韩字符每字算 1，其他语言按词算 1（与楼层正文计数器一致）；
  - `字符数`：去掉空白后的字符数（含标点）。
- **千楼可用**：当前聊天直接从上下文读取；其他聊天逐个读取，计数分块让出 UI；楼层列表默认每页 100 层，可切换 50/100/200/500 或跳页。
- **缓存**：按聊天文件大小/最后消息/楼层数做签名，规则不变时二次打开直接复用；点“刷新”可强制重算。
- **导出 CSV**：汇总表和逐层明细一起导出，Excel 可直接打开。
- **只读**：不写聊天、不改角色卡、不发消息。

## 安装

### TauriTavern

> TauriTavern 的“安装扩展”界面只接受 Git 地址，不识别 zip；请先把压缩包解压，再把 `chat-word-count` 文件夹复制到下面任一目录，然后刷新页面。

二选一：

1. **本地扩展（推荐）**
   把整个 `chat-word-count` 文件夹放到：
   `…\data\default-user\extensions\chat-word-count\`
   使路径类似：
   `…\data\default-user\extensions\chat-word-count\manifest.json`

2. **全局扩展**
   放到：
   `…\data\extensions\third-party\chat-word-count\`

然后重启 TauriTavern，或刷新页面；在扩展列表里启用“角色卡字数统计”。

> TauriTavern 只支持纯前端扩展，本扩展不需要 Node 服务端，符合该限制。

### SillyTavern

把 `chat-word-count` 文件夹放到：
`…\SillyTavern\data\default-user\extensions\chat-word-count\`

刷新页面，在“扩展”里启用。

## 使用

1. 打开一张角色卡（先进入任意一个聊天）。
2. 点顶部魔杖菜单里的 **“角色卡字数统计”**。
3. 选择规则：
   - 想看“正文”：点 **“只看 `<content>`”**；
   - 想看“去掉思考/状态后的全部文字”：用默认规则；
   - 自定义：在标签框里输入，例如 `content, dialogue`，选择“只取标签”；或输入要排除的标签，选择“排除标签”。
4. 点 **“应用并统计”**。
5. 点聊天表里的任意一行，下方会显示该聊天每一层的字数；楼层多时用分页。
6. 需要表格时点右下角 **“导出 CSV”**。

### 标签写法示例

```text
content
```

```text
<content>
```

```text
think, details, status
```

只取标签模式会取标签内部的文字；排除模式会把整个标签块（含标签本身）去掉。

## 计数口径

与“楼层正文计数器”保持一致：

1. 先按规则得到正文；
2. 去掉代码块（``` / ~~~）、HTML 注释、图片、链接地址（保留链接文字）、行内代码、`{{宏}}`、URL、HTML 标签、Markdown 行首标记；
3. 汉字/假名/谚文每字计 1；去掉这些字符后，其余语言/数字串按“词”计 1；
4. 标点、空白不计入“字数”；“字符数”会统计去空白后的所有字符（含标点）。

因此，同一条消息在本插件里的单层数字，应与楼层正文计数器徽标一致（前提是规则相同）。

## 千楼/性能

- 当前聊天优先使用 `getContext().chat`（完整数组），不会因为 DOM 窗口化而漏楼层。
- 其他聊天通过 `/api/chats/get` 逐个读取，每 40 条让出一次 UI，可随时取消。
- 不会一次性把几千层 DOM 全部插入；楼层列表按页渲染。
- 统计结果按角色缓存在浏览器 `localStorage`，聊天没变化时二次打开很快；点“刷新”强制重算。
- 若 TauriTavern 开启了“历史滑动按需加载”，检测到历史槽位为 `null` 时会自动改走接口全量读取。

## 限制

- **群聊暂不支持**：群聊的聊天文件属于多个角色，字数归属会混淆。
- 统计的是每条消息当前的 `mes` 正文，不包含未选中的 swipe 分支。
- 只读取当前酒馆数据目录里该角色卡的聊天；不会跨设备/跨数据目录。
- 如果聊天列表接口失败，会保留当前聊天并显示错误提示，可点“重试”。

## 隐私

所有统计都在本地浏览器内完成，只向当前酒馆的本地接口读取聊天；不会上传任何内容。缓存只写入 `localStorage`，可在浏览器设置中清除。
